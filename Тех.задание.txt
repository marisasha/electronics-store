FastApi проект

название: Магазин электротехники

Необходимо реализовать следующий функционал: 
- [ ] Систему регистрации/авторизации
- [ ] Личный кабинет
- [ ] Каталог товаров
- [ ] Выборку популярных товаров
- [ ] Корзину с товарами 
- [ ] Понравившиеся товары 
- [ ] Систему поиска товаров
- [ ] Карточка товара / цена , описание , фото , отзывы о товаре 
- [ ] Статья о интересных товарах 
- [ ] Акции и скидки 
- [ ] Функционал покупки товаров 
- [ ] Панель для продавца , т.е разграничение по доступу superadmin / admin / salesclerk / user
- [ ] Уведомления
- [ ] Сообщения на почту о новых акциях , скидках


Задачи реализации проекта.
- Основной фреймворк Fastapi
- База данных Postgres
- Кэш будет хранится в Redis
- Система уведомления на почту будет вынесена в Celery в связке с RabbitMq
- Поиск товара , добавление в понравившиеся и в корзину будет вынесено в Go 
- Система оплаты в ЮКасса
- Проект будет запускаться с помощью docker-compose
- Обязательное тестирование кода !!!

- При выполнение всего ниже перечисленного, конечной целью является запуск проекта в продакшен
